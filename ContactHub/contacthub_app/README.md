# contacthub_app

The Contact Hub app, in Flutter (web, Android, iOS and Linux from one
codebase). For now it's a welcome screen
([lib/welcome/](lib/welcome/welcome_screen.dart)) with the request box
([lib/request/](lib/request/)), typed or dictated on the device.

Run it from the repo with `devbox services up` or `devbox run web`, and
build it with `make` (see the [project README](../README.md)). Test it
here with `flutter analyze` and `flutter test`.

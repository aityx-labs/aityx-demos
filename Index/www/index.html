No key yet?

  1. Sign up at aityx.ai.
  2. In the aityx console, open API keys and create one.
  3. Paste it here and choose Check and save.

The key stays in this browser, for the demos on this address: each calls aityx with it, straight from the page. Check and save makes one empty call to aityx, which runs no model. Use Only this session on a shared computer.

Six apps, each with its own aityx models

The six apps run from this page's address, each under its own path: start them with ./start-aityx.sh at the root of the repository, stop them with ./stop-aityx.sh. Each uses the key above. Or open them in a GitHub codespace from a card, or all six at once.

# Fonts

`RobotoMono-Regular.ttf`: Roboto Mono, Copyright 2015 The Roboto Mono
Project Authors (Google), under the
[Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0). Taken
from the Flutter SDK, which ships it with DevTools
(`bin/cache/dart-sdk/bin/resources/devtools/assets/fonts/Roboto_Mono/`).
The JSON viewer uses it: Flutter on the web has no monospace font of its
own.

# riverrace_app

The RiverRace app, in Flutter (web, Android, iOS and Linux from one
codebase): the game ([lib/game/](lib/game/)), the aityx pilots'
strategies and their cards ([lib/strategy/](lib/strategy/)), the race
screen ([lib/race_screen.dart](lib/race_screen.dart)), and the side panel
with every call to aityx ([lib/calls/](lib/calls/)).

Run it from the repo with `devbox services up` or `devbox run web`, and
build it with `make` (see the [project README](../README.md)). Test it
here with `flutter analyze` and `flutter test`.

# roborules_app

The RoboRules app, in Flutter for the web: Robocode's window, the
battlefield, the robot list and the rules editor
([lib/ui/](lib/ui/)), and the battle's client and controller
([lib/battle/](lib/battle/)). Every turn it shows comes from aityx through
the API.

Run it from the repo with `devbox services up` or `devbox run web`. Test it
here with `flutter analyze` and `flutter test`.

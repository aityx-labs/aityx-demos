# datyx_dashboard

The datyx dashboard, a Flutter web app: it invokes the datyx API
([../../datyx/](../../datyx/)) and shows what it answers, with every
call in a side panel. Views only: the data and the logic live in the API.

Run it from the folder above: `devbox services up` serves the release
build on http://localhost:9906/app/, `devbox run web` runs Flutter's dev
server with hot reload. See the [README](../README.md) there.

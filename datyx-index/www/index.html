A data system in the making: its API, its dashboard, HealthHub, and the catalogue behind them.

github.com/aityx-labs/aityx-demos

The datyx group

Everything runs locally on its own port, 9800 to 9906: start the group with ./start-datyx.sh at the root of the repository, stop it with ./stop-datyx.sh; or docker compose up in each folder. Or open the group in a GitHub codespace. The six aityx demos have an index of their own, on port 8800.
